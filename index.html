Map colors — quick and easy 👀

Confirmed Booking — yesss 💜 this one is happening. Time to plan the real trip.

Event coming up soon — purple with a neon-red ring. The closer the date gets, the stronger the ring. Important: the ring only means the event is getting close. It does not mean the booking is confirmed.

Contacted — message sent. Now we wait, follow up, or act very patient 😌

Open / Pending — interesting lead, not contacted yet.

Parked — not a “no”. Just not important right now.

Past event — the event date is already over. Stage Scout does this automatically.

Several pins in the same place? Stage Scout spreads them a little, so they do not hide behind each other. The small line shows the real place.
Status — keep it simple
When you edit a target, choose: Open / Pending, Contacted, Parked, or Confirmed Booking.
You do not need to set Past event. The date does that for you.
Priority — how interesting is it?
High = very interesting / worth your attention.
Medium = interesting, but not urgent.
Low = only worth it for a special reason.
Simple workflow 😏
1. Find an interesting event, venue, festival, agency, or production.
2. Check if it fits you.
3. Check pay + travel + hotel + technical setup before we fall in love with the poster. Very romantic, I know 😂
4. If it looks good, contact them → set status to Contacted.
5. Add Last Contact + Follow-up Date.
6. They say yes? → Confirmed Booking 💜
Booking Facts — the useful stuff
The most important things are: Performer Pay, Application Fee, Travel, Accommodation, Venue, Technical Setup, Eligibility, Deadline, Contact Info, Response, and Next Action.

If we cannot find something online, use Not publicly stated. Better than guessing 😇
Reminders 🔔
Upcoming reminders shows the next follow-ups, deadlines, and event dates.
Click one and the map opens the right target. You can also add follow-ups, deadlines, and events to your calendar.
Research — what do we really know?
This part shows what we checked, what is old information, and what is still unknown.
The source links stay with the target, so we do not need to start from zero every time 🕵️‍♀️
Location shortcut
Enter the event / target, city / area, and country. Then press Find coordinates from name / city.
Stage Scout fills in latitude + longitude for you.
Shared between us ❤️ When you are signed in, saved changes sync through the shared cloud. If you change something, M can see it too — and the other way around.
