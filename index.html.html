Stage Scout — Quick Guide 🤓

The tiny Manuel-style manual so nobody has to guess what the buttons mean.
Map colors

Confirmed Booking — it is happening. Time to plan the real trip.

Contacted — message sent, now we wait or follow up.

Open — interesting lead, not contacted yet.

Parked — not worth chasing right now.
Priority
High = strong fit / worth attention.
Medium = interesting, but not urgent.
Low = only worth it for a special reason.
Simple workflow
1. Find a good event / agency / production.
2. Add the target and verify the source.
3. Check pay + travel before getting excited 😅
4. Contact them.
5. Set Last Contact + Follow-up Date.
6. If they say yes → change Status to Confirmed Booking 💜
Good fields to keep updated
Pay / Fee · Travel / Hotel · Application Deadline · Contact Info · Response Status · Next Action. If a number is not published, write Not published instead of guessing.
Location shortcut
Type the Event / Target, City / Area and Country, then press Find coordinates from name / city. The map will fill Latitude + Longitude for you.
